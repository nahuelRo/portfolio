# Portfolio — Nahuel Rodriguez

Portfolio estático en Astro. Hub profesional en español para experiencia, proyectos y contacto.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- Astro (static)
- TypeScript
- Tailwind CSS
- Content Collections
